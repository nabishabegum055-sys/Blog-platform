# 🚀 Modern Blog Platform using Flask

A simple and modern blog platform built using **Python Flask**.
This application allows users to create, view, and interact with blog posts in a clean and responsive interface.

---

## ✨ Features

* 🔐 User Registration & Login
* 📝 Create, Edit, and Delete Blog Posts
* ❤️ Like System
* 💬 Comment System (with username & timestamp)
* 🖼️ Blog Image Support
* 🔍 Search Functionality
* 🌙 Dark Mode Toggle
* 📱 Responsive UI (Bootstrap)

---

## 🛠️ Technologies Used

* Python (Flask)
* HTML, CSS, JavaScript
* Bootstrap (UI Design)
* JSON (Data Storage)
